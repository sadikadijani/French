# Cahier de Français

A personal French practice app: texts with tap-to-translate and class-style transformation drills, "Ma journée" (tell your day), spaced-repetition vocabulary, a grammar ladder with a conjugator, shadowing, a 60-second speaking timer, and a mistake notebook.

Open `index.html` in any browser, or publish it with GitHub Pages.

## What works outside Claude
- Read-aloud (your device's French voice), shadowing, flashcards, grammar drills, conjugator, built-in texts and translations, mistake review, levels.
- Progress is saved in the browser you use (per device).

## What needs the Claude version
Translation of new text, corrections, conversations, generated stories and preparing teacher texts use Claude, and only work when the app is opened inside Claude.
